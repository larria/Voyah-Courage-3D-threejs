# 功能对齐记录 · v1.1.1

参考本地 `知音3d` 项目的实际实现（`components/car-player.js`、`charging-controls.js`、`mirror-controls.js`、`tools/direct-player.js` 和 `components/API.md`），在现有 three.js 展厅中补齐可展示的功能。参考项目是原始 Unity 播放器的封装；本项目重建交互和画面，不宣称两种引擎像素、动画时序或所有副作用完全一致。

| 功能 | 原先缺项 | 本次实现 |
| --- | --- | --- |
| 灯组 | 一个总开关，日行灯与大灯绑定 | 前大灯/尾灯、日行灯、位置灯独立；保留总开关；转向时日行灯转向段临时变为琥珀色 |
| 后视镜 | 固定网格 | 双镜 70°折叠、3 秒 smoothstep，快速反向从当前进度继续；与车门变换组合 |
| 锁车 | 无入口 | 锁车收镜并熄灯、解锁展镜并亮灯；短暂转向灯反馈，不改变门窗 |
| 寻车与转向 | 灯件未控制 | 转向闪烁和寻车展示，结束恢复最新灯组状态；次数为本项目的演示选择 |
| 充电盖板 | 固定网格 | 从原始 CDK 锚点及参考桥读取开闭姿态，独立控制盖板 |
| 充电线缆 | 导出后始终隐藏 | 显示/隐藏原始插头及线缆，按右后插口位置对齐；开盖完成后显示插头 |
| 充电流光 | 无 | 在线缆上移动的亮带；开启时开盖、连线并停车，停止只停流，保留盖板和线缆 |
| 充电联动 | 无 | 独立关盖在连接线缆时拒绝；隐藏线缆会停止流光并关盖；连线时拒绝开始行驶 |
| 内饰模式 | 只有相机预设 | 独立进入/返回按钮，返回进入时的外观相机，保留配色；清除拖动惯性避免相机漂移 |
| 模型点击 | 只有配置按钮 | 点击车门、玻璃、尾门、镜子或盖板操作对应部件，拖动旋转不误触开合 |
| 即时门窗 | 只有动画 | 可切换即时开合；动画模式保留原有两秒行程 |
| 沉浸欣赏 | 无 | 隐藏界面并尝试全屏，支持恢复按钮、Esc 和系统退出全屏；不支持全屏时仍可沉浸 |
| PWA/离线 | 仅普通静态站 | 安装清单与图标、完整资源缓存、离线重载、缓存完整后显示状态；新版确认后更新，相同内容复用缓存 |

参考 README 的旧充电说明与实际代码有差异。本次按 `charging-controls.js` 及 API.md 的当前行为处理：停止流光保留线缆；隐藏线缆才会关盖。行驶与充电互斥、开盖的 0.8 秒过渡，以及寻车/转向闪烁次数，是本项目的展示交互选择。

`web/public/interactions.json` 包含 73 个模型实例的原始层级绑定、盖板开闭矩阵及源场景 SHA-256。门件使用原始层级归属，左右镜通过各自烘焙矩阵保留镜像方向；不再依赖包围盒中心推断所属车门。网格、贴图及原始 Unity Build 保持原有资源，仅新增锚点数据。完整提取脚本补齐了坐标转换，并在导出结束时自动刷新锚点。

本项目的 `window.carViewer` 提供规范控制方法及目标状态，`getState()` 还包含后视镜/盖板动画进度。门窗 boolean 表示目标状态，方法返回不表示行程已结束；这是 three.js 内部状态，不是 Unity 或真实车辆回读。接口在模型加载完成后可用，当前不提供可重复挂载的组件生命周期。

未把参考项目的实验命令全部照搬：门把手数组在该车型为空；`setCarseat` 只证明选装资源切换，不代表座椅调节；版本/选装组合、开场动画重播、独立轮转角和车标额外语义未充分验收。这些仍保留为未对齐范围。

验证：`npm test` 检查后视镜反向/端点、充电状态与盖板姿态、独立灯组/闪烁恢复、非法开关参数。`verification/browser-check.py` 运行生产构建的桌面/手机按钮操作、模型点击、动画、画面差异、子路径、完整断网重载及等待确认的版本更新；JSON 结果保存为 `verification/browser-results.json`，截图在同目录且不提交。


## v1.1.1 后视镜方向修正

v1.1.0 在烘焙后的镜壳坐标系中误用了正 70°，导致左右镜壳向车外偏移。修正为局部 Z 轴负 70°；原有 3 秒 smoothstep、快速反向及开门联动保持不变。新回归测试读取真实 DOOR_HSJ 网格，检查两侧镜壳重心折叠后距车身中线缩小且向车后移动，展开后恢复原位，避免只验证旋转矩阵而漏掉物理方向。

`verification/mirror-direction-check.py` 验收左右两侧画面、锁车/解锁、开门折叠、快速反向与重复命令，结果保存为 `verification/mirror-direction-results.json`。
